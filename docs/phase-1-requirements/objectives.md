# Project Objectives

The primary academic and software engineering objectives of the Student Information System project are defined as follows:

| Ref ID | Objective | Description |
| :--- | :--- | :--- |
| **OBJ-01** | **Centralized SIS Platform** | Develop a centralized, digital Student Information System to streamline academic record-keeping. |
| **OBJ-02** | **Rigorous OOAD Application** | Apply Object-Oriented Analysis and Design principles (abstraction, encapsulation, inheritance, polymorphism, cohesion, coupling) across all lifecycle phases. |
| **OBJ-03** | **Student Record Management** | Manage student registration, profile information, and lifecycle data systematically. |
| **OBJ-04** | **Course & Enrollment Management**| Provide structured mechanisms for course creation, faculty assignment, and student course enrollments. |
| **OBJ-05** | **Attendance Tracking** | Enable faculty to accurately record and update attendance, while allowing students to monitor their attendance history. |
| **OBJ-06** | **Academic Records & Marks** | Facilitate marks entry, record persistence, grade computation, and student academic performance viewing. |
| **OBJ-07** | **Error Reduction** | Minimize human data entry errors and eliminate duplicate records through centralized data validation. |
| **OBJ-08** | **Data Accuracy & Consistency** | Maintain relational and business data integrity across interconnected entities (students, courses, faculty, attendance, marks). |
| **OBJ-09** | **Role-Based Security** | Implement secure authentication and fine-grained authorization for Admin, Faculty, and Student roles. |
| **OBJ-10** | **Maintainable & Scalable Architecture** | Build a modular, decoupled software solution that allows straightforward maintenance and future functional scalability. |\n
