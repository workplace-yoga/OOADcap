# Production CORS & Security Boundary

## 1. Cross-Origin Resource Sharing Policy
- **Authorized Origins**:
  - `https://yogan.github.io` (Production GitHub Pages)
  - `http://localhost:5500`, `http://127.0.0.1:5500` (Local Dev Servers)
- **Allowed HTTP Methods**: `GET, POST, PUT, DELETE, OPTIONS`
- **Allowed Headers**: `Content-Type, Authorization`
