# The Complete OOAD Engineering Narrative

## 1. The Core Engineering Journey

```
[ 1. Real-World Problem ]
Institutional record fragmentation, manual paper logs, attendance calculation errors, lack of role security.
           │
           ▼
[ 2. Requirements & Scope Freeze (Phase 1) ]
Defined 21 Functional Requirements (FR-01..21), 8 Non-Functional Standards (NFR-01..08), and 3 Actors.
           │
           ▼
[ 3. Object-Oriented Analysis (Phase 2) ]
18 Detailed Use Cases, Actor Profiles, CRC Cards (Class-Responsibility-Collaborator), Conceptual Domain Model.
           │
           ▼
[ 4. Object-Oriented Design & UML (Phase 3) ]
Domain Classes with encapsulated attributes and operations, 8 Sequence Diagrams, 4 Activity Diagrams, State Machine.
           │
           ▼
[ 5. System Architecture & Database Design (Phase 4) ]
5-Layer Architecture (Presentation -> Application -> Domain -> Persistence -> DB), 3NF 8-Table Schema, 15 REST APIs.
           │
           ▼
[ 6. Full Application Implementation (Phase 5) ]
Pure Domain Entities (User, Student, Course, Enrollment, etc.), Services, Repositories, Glassmorphism Client SPA.
           │
           ▼
[ 7. Integration & Quality Validation (Phase 6) ]
28 Automated Test Suites, 100% Pass Rate, RBAC boundary enforcement, IDOR mitigation, Security audit.
           │
           ▼
[ 8. Production Cloud Deployment (Phase 7) ]
GitHub Pages (Frontend SPA) + Render (Node.js REST API Web Service) + Cloud Relational Storage via HTTPS.
```
